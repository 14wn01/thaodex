# GitProject

Bài tập Git: quản lý README và hai trang HTML trong source/.

## Các lệnh
- `git clone <url>`: sao chép repository cùng lịch sử.
- `git add README.md source/`: đưa thay đổi vào staging area.
- `git commit -m "Add source files"`: lưu snapshot có thông điệp.
- `git push origin main`: đồng bộ commit lên remote.
- `git status`: kiểm tra trạng thái.

Dự án được lưu trong thư mục riêng thuộc repository thaodex theo lựa chọn của chủ tài khoản.
