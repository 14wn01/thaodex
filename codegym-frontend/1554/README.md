# Phân tích Website Template

Trang tham khảo: https://codegym.vn/codegym-career/

- Header và menu đặt đầu trang để nhận diện thương hiệu, tiếp cận chương trình.
- Hero dùng tiêu đề lớn và CTA, dẫn vào nội dung lợi ích và lộ trình.
- Content chia nhóm: chương trình, thực hành, dự án, hỗ trợ nghề nghiệp.
- Footer đặt thông tin liên hệ và các liên kết tài nguyên.

Bản dựng này chỉ tái hiện bố cục ở mức đơn giản, sử dụng HTML5 và CSS Grid. Chưa đính kèm ảnh chụp trang gốc.
